使用规范

从「找」到「调」到「拿走」，四步。后面是动效本身该怎么用。

找组件 调参数 拿走代码 转到 AI 动效规范 无障碍 快捷键 离线说明 常见问题

一、找组件

组件库按「界面类型」分 10 类，不按技术实现分。先想你要的是哪一种界面，再进那一类挑动效。

按分类列表与卡片 / 表单与输入 / 反馈与提示 / 数据与进度 / 媒体与展示 / 控件与切换 / 地图与空间 / 消息与社交 / 个人与设置 / 设备与流程
按设备手机 / 平板 / 笔记本 / 桌面 / 自助机 / 车机 / 电视 / 手表 / AR·VR / 墨水屏 / 工业屏
按关键词组件名、场景名、动效名都能搜。例如「购物车」「逐项错峰」「手表」。
卡片墙相邻两张一定换界面也换动效。看到两张长得一样，说明你筛得太细或搜索词太宽。

二、调参数

详情页的三个按钮：重播 / 调参数 / 对比默认。

  • 调参数：时长、缓动、幅度；「逐项错峰」还多一个错峰间隔。拖滑杆画面立刻变，不用刷新。
  • 对比默认：舞台一分为二，左边出厂参数、右边你调过的，同一时刻起播，差多少一眼看得出来。
  • 重播：按当前参数把动画拉回第 0 帧重放。

幅度怎么理解

幅度是「基准量的倍数」。1.00× 是默认；1.5× 位移、缩放、模糊半径、光晕、抖动都会放大到 1.5 倍。想让动效说得更重就往上推，想更克制就往下压到 0.6–0.8。

缓动怎么选

  • 减速——元素进场、弹层出现。默认选它。
  • 缓减速——距离长的位移，收尾更软。
  • 对称——遮罩揭开、翻页这类「拉开」的动作。
  • 回弹——强调、轻量反馈。高频列表不要用。
  • 匀速——进度条、跑马、循环类。

许可速查

组件代码可以免费用于个人项目与商业项目，不强制署名。只有一种情况不允许：把整个库打包成你自己的组件库去卖或公开发布。

可以放进产品、客户项目、收费软件；改类名改配色改曲线；团队内部共享与二次封装。

三、拿走代码

详情页右侧有四个代码页签：HTML / CSS / JS / AI 提示词，以及两个按钮：「复制当前代码」「下载单文件」。想一次看十种开发路径的写法，点组件卡片左上角的「↓」，会跳到接入指南的接入台。

  • CSS 已经排版成可读格式，一条规则一个块，复制进样式表就能用。
  • 根节点 class 形如 fx-s001-01，样式全部限定在它下面，不会污染你的全局。
  • 动效数值走 CSS 变量：--fx-dur / --fx-ease / --fx-amp / --fx-gap。改变量就能改行为。
  • 默认是循环演示。接进项目时改成单次播放：把 animation 写成 … both 并删掉 animation-delay，CSS 里有注释写明。
/* 演示用：循环 */
animation: kfx-s001-01 calc(var(--fx-dur) * 8.33) var(--fx-ease) infinite;

/* 接入项目：播一次 */
animation: kfx-s001-01 var(--fx-dur) var(--fx-ease) both;

四、转到 AI

「AI 提示词」页签里给出的是一段一条龙的提示词：结构、时长、缓动、幅度、禁止事项、验收清单、完整参考实现全在里面。

  • 点「复制 AI 提示词」，提示词连同你调好的参数一起进剪贴板。
  • 点「复制并打开 ChatGPT / Claude / DeepSeek / Kimi」，会先把提示词复制好，再用系统默认浏览器打开对应站点，粘贴即可。
  • 桌面版的网络请求只有这一种：打开浏览器。应用本身不联网。

五、动效规范

时长

120–200ms微反馈：按压、hover、图标切换
240–320ms常规进场：卡片、行、气泡
360–480ms页面级转场、大面板
600ms+只用于有物理感的回弹、弹簧

按场景选动效

  • 入场：上滑 / 放大 / 遮罩揭开。一屏最多两种入场，别每个元素都动。
  • 列表：逐项错峰，间隔 60–80ms，超过 6 项就截断延迟。
  • 加载：骨架呼吸或微光扫过二选一。加载完必须撤掉。
  • 循环：呼吸、外发光、悬浮抬升。幅度要小，否则抢注意力。
  • 交互：涟漪、按压、抖动。抖动必须配文字说明，不能只靠抖动传达失败。
  • 状态：边框流光、进度填充。只在状态真的变化时播。
  • 退场：退出缩放。删除、关闭、超时的标准收尾。

硬规则

  • 只动 transform / opacity / filter，不要动 width / height / top / left。
  • 同一时刻不要有超过 3 处动效在跑。
  • 无限循环的动效必须能被关掉（本应用在「设置 → 卡片里播放动效」）。

六、无障碍

  • 每个组件都应响应 prefers-reduced-motion：位移与缩放降级为透明度过渡，循环类直接停止。
  • 本应用默认开启动效（内容是动效库），但「设置 → 减少动效」可以一键关掉页面转场与循环动画。
  • 动效不能是唯一的信息载体：错误要有文字，状态变化要有可读标签。
  • 键盘能完成同样的操作，焦点要可见。

七、快捷键（桌面版）

  • Esc 全屏时退出全屏
  • F11 切换全屏
  • 鼠标右键 全屏时退出全屏
  • 详情页：重播 / 调参数 / 对比默认 三个按钮
安卓版没有全屏快捷键；界面本身已是全面屏。所有按钮都有可点区域，单手握持也够用。

八、离线说明

应用本身完全离线：字体是本地 woff2 子集，没有任何 CDN、外链图片或统计脚本；安卓版不申请 INTERNET 权限。

唯一的网络行为是桌面版点击外部链接时调用系统默认浏览器打开。打不打开、用哪个浏览器，由你的系统设置决定，应用不做任何预置。

九、常见问题

为什么卡片里有的组件是空的？

两种可能：一是它本身是「骨架屏 / 加载态」组件，占位块就是内容；二是动画正好停在不可见的那一帧，等一下或点重播。

复制出来的代码运行后不动？

大概率是把循环改成了单次却没加 both，或者外层容器给了 overflow: hidden 把位移裁掉了。CSS 注释里写了接入写法。

调好的参数会丢吗？

详情页的参数只作用于当前这一条；关掉页面就回到默认。想留住就把它复制走——CSS 变量块和 AI 提示词里都会写成你调过的值。

能搜索英文吗？

能。组件名、场景英文名、动效英文名都参与搜索。
