一、设计令牌

整个组件库共用这一套颜色、时长与曲线。照抄进你的项目，组件放进去就不会违和。

:root {
  /* 颜色 */
  --tz-acc: #C6F24C;        /* 主色 */
  --tz-acc-deep: #4F6B00;   /* 主色深字 */
  --tz-line: #E7E4DA;       /* 描边 */
  --tz-surface: #FFFFFF;    /* 卡面 */
  --tz-soft: #F4F3EE;       /* 浅底 */
  --tz-ink: #14160F;        /* 主字 */
  --tz-ink-2: #7B8072;      /* 次字 */
  --tz-danger: #E5484D;

  /* 时长 */
  --tz-dur-instant: 120ms;
  --tz-dur-fast: 160ms;
  --tz-dur-base: 240ms;
  --tz-dur-standard: 320ms;
  --tz-dur-emphasis: 480ms;

  /* 曲线 */
  --tz-ease-out: cubic-bezier(.16, 1, .3, 1);
  --tz-ease-outc: cubic-bezier(.33, 1, .68, 1);
  --tz-ease-inout: cubic-bezier(.76, 0, .24, 1);
  --tz-ease-spring: cubic-bezier(.34, 1.56, .64, 1);
  --tz-stagger: 70ms;
}
组件的 CSS 不依赖这些变量——它们只是给你对齐用的。组件内部用的是自带的 --fx-*。

三、AI 提示词模板

三种常用场景，直接复制给任意 AI。想要某个具体组件的完整版本，去组件详情页点「复制 AI 提示词」，那份更细。

模板 A · 复刻一个组件

你是资深前端动效工程师。请实现一个「商品列表逐项错峰入场」组件。

【结构】三行商品卡：左侧 30px 方形缩略图 + 中间标题/副标题 + 右侧价格。
【动效】子项依次上浮 18px 进入，每项延迟 70ms，时长 420ms，
        缓动 cubic-bezier(.16,1,.3,1)。
【约束】
1. 只用 HTML/CSS，不引框架与外部资源；
2. 只动 transform 与 opacity；
3. 根类名 .tz-list，样式不污染全局；
4. 加 @media (prefers-reduced-motion: reduce) 降级为透明度过渡。
【输出】只输出一个 html 代码块，不要解释。

模板 B · 给现有页面加入场

下面是我的现有组件结构（贴代码）。请在不改动结构的前提下，
给它加一个「自下而上 24px、透明度 0→1、360ms、ease-out-expo」的入场动效，
并要求：只动 transform/opacity；进入后不再重播；
列表子项按 60ms 错峰；尊重 prefers-reduced-motion。

模板 C · 把写死的动效改成可配置

把下面这段 CSS 动效改成用 CSS 变量驱动：
--fx-dur（时长）、--fx-ease（缓动）、--fx-amp（幅度倍率）。
位移、缩放、模糊半径都要乘 --fx-amp；关键帧里用 calc() 表达。
保持默认值与现在一致，输出改造后的完整 CSS。

四、Cursor / Windsurf 规则

把下面这段存成项目根目录的 .cursorrules（Windsurf 存成 .windsurfrules）， AI 写界面时会自动遵守这套动效规则。

# 动效规范（Zingdex）
- 只动画 transform / opacity / filter；禁止动画 width、height、top、left、margin。
- 时长：微反馈 120–200ms，常规进场 240–320ms，页面转场 360–480ms，回弹 600ms+。
- 缓动优先 cubic-bezier(0.16, 1, 0.3, 1)；对称动作用 cubic-bezier(0.76, 0, 0.24, 1)。
- 列表错峰 60–80ms，超过 6 项截断延迟。
- 同一屏最多 3 处动效同时跑。
- 必须加 @media (prefers-reduced-motion: reduce)：位移与缩放降级为透明度过渡，循环类停止。
- 组件根类名统一前缀，样式不污染全局。
这几条和「使用规范 → 动效规范」是同一套，改了那边记得同步这边。

八、批量取代码

组件库的完整数据在交付包的 04_源代码/…/04_动效代码库/spec/catalog.json，每条都带成品 HTML 与 CSS：

{
  "id": "s001-09",
  "name": "逐项错峰",
  "group": "列表与卡片",
  "dur": 420,
  "easeValue": "cubic-bezier(0.16,1,0.3,1)",
  "params": [ { "k": "dur", "v": 420, "min": 120, "max": 2600 } ],
  "code": { "html": "<div class=\"fx-s001-09\">…</div>", "css": "@keyframes …" }
}

用脚本按 group 或 shell 过滤，就能一次性导出某一类的全部组件。

九、常见坑

复制过去不动

三个原因：一是把循环改成了单次却忘了 both；二是外层容器 overflow: hidden 把位移裁掉了； 三是组件依赖 JS 初始化（比如磁吸按钮），你只贴了 HTML 和 CSS。详情页的 JS 页签会告诉你要不要贴。

类名冲突

组件根类名形如 fx-s001-01，内部选择器全部挂在它下面，一般不会冲突。 如果你的项目也有 .ui 这种通用类，把组件的选择器一起改名即可。

字体看着不一样

组件用的是系统字体栈，不含任何内置字体。你项目里如果全局指定了别的字体，组件会跟着变——这是故意的，方便融入。

动画在 Safari 上不跑

检查是否用了 backdrop-filter（玻璃面板），Safari 需要 -webkit- 前缀，组件里已经带上了。
