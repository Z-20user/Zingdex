显示

影响整个应用的观感。

主题 浅色适合长时间看；跟随系统会随操作系统的深色模式切换。
特色皮肤 在浅色 / 深色之上叠一层氛围。只加背景装饰，不改文字颜色，不影响阅读。
界面密度 紧凑会缩小内边距和间距，一屏能多放一档内容。
界面字号 整体缩放整个界面，组件预览会跟着一起缩放。看不清就调大一档。
卡片尺寸 组件库卡片里预览区的高度。大一点看得清，小一点一屏能多放一行。
代码字号 详情页与接入台里代码块的字号，跟界面字号分开调。
行距 文字密度的另一半。宽松适合长时间阅读，紧凑一屏能多放几行。

动效

本应用的内容本身就是动效，这里控制它播不播。

卡片里播放动效 关掉后组件库的卡片只显示落定状态，滚动更省电，适合低配机器。
减少动效 关闭页面转场与循环动画，等同系统的「减少动态效果」。

组件库

打开组件库时的默认状态。

默认页签 进入组件库时先看哪一类。
默认设备 只保留在这类设备上能用的动效。
默认排序 推荐排序按动效与界面的契合度排；名称按拼音/字母；时长从短到长。
每次加载 一屏先出多少张卡，点「加载更多」再加。

桌面窗口

只在 Windows 桌面版里生效。

启动时全屏 打开应用直接进全屏，展示动效时没有窗口边框干扰。
随时进出全屏 全屏时按 Esc、点鼠标右键，或按 F11 切换。窗口模式下按 F11 回到全屏。
退出全屏快捷键 点右边录制，再按下你习惯的组合键。Esc 始终保留，不会被占用；和系统或其他功能冲突时会提示。
开机自动启动 登录 Windows 后自动打开。写在当前用户的启动项里，不需要管理员权限；关掉就从启动项移除。
