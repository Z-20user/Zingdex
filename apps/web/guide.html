接入指南

在组件库里点卡片左上角的「↓」，会直接跳到这一页，整页按这个组件重排：预览、十种开发路径的代码、右上角一键复制。

01 / COPY

复制代码

组件详情页切到 CSS / HTML / JS 标签，点「复制当前代码」。代码里不带框架依赖，类名统一 tz- 前缀，可以整体改名。

  • HTML 结构直接放进页面
  • CSS 放进样式表或 <style>
  • 需要交互的组件，JS 放在页面底部执行
02 / FILE

下载单文件

点「下载单文件」得到一个完整 HTML，双击就能在浏览器里跑。适合先验证效果，再拆进项目。

文件不含任何外链，断网也能打开。

03 / AI

用 AI 再创作

点「复制 AI 提示词」，得到一段包含效果描述、参数、性能约束和参考实现的提示词。丢给任意 AI，可以让它改方向、换风格、扩成整套动效。

目录里标「规划中」的条目也能复制提示词，直接让 AI 生成。

上线前检查

  • 动画只改 transform 与 opacity
  • 给长时间移动的元素加 will-change，结束后移除
  • 尊重 prefers-reduced-motion
  • 键盘能完成同样的操作，焦点可见
  • 动效不超过 600ms，或提供进度反馈
  • 类名 tz- 与你的项目不冲突，冲突就整体改名
