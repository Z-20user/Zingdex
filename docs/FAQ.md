# 常见问题 / FAQ

---

## 关于内容

**20,000 条是怎么来的？是复制粘贴凑数吗？**

不是。20,000 条 = 201 个场景 × 每个场景下的十几个条目。
每条都由生成脚本从设计令牌展开，指向 500 个手写的基础特效之一。
所以严格说：**201 个场景是真的，20,000 个场景-条目组合是真的，500 个特效实现是真的**。
说自己「有 20,000 个动效」会夸大，这个项目不这么讲。

**500 个基础特效是原创的吗？**

是。全部手写 CSS / Canvas，关键帧名前缀统一。已对 Animate.css、Animista、GSAP、
Framer Motion、Anime.js、Lottie 等 8 类库做过特征串扫描，命中 0。
方法与结果见 [`DATA-PROVENANCE.md`](DATA-PROVENANCE.md)。

**和网上那些动效库有什么区别？**

多数动效库给你一个 div 起飞。这里每条都是**一块真实界面**（商品列表、设置页、播放器）
加上作用其上的动效，复制走能直接用，不用自己补结构。

## 关于授权

**能商用吗？**

能。代码 Apache-2.0，数据与文档 CC BY 4.0，两者都允许商用。

**要付钱吗？要申请吗？**

不要。也不需要注册账号。

**要署名吗？**

- 用**代码**：保留版权声明、Apache-2.0 文本和 `NOTICE` 文件
- 用**数据**：在文档或关于页注明来源

最小署名形式：

```
Motion data based on Zingdex 跃索 (CC BY 4.0)
https://github.com/Z-20user/Zingdex
```

**能把 20,000 条数据打包转卖吗？**

可以，CC BY 4.0 允许。但必须署名并保留许可证说明。

**能改名换皮当自己的产品发吗？**

代码层面可以（Apache-2.0 允许）。但：

- 不能用「Zingdex」「跃索」当产品名
- 不能用原图标
- 不要沿用包名 `com.transientlab.motion`

见 [`../TRADEMARK.md`](../TRADEMARK.md)。

**为什么不用 MIT 了？**

3.0 及之前是 MIT。改双许可的原因是：MIT 对数据与文档的署名没有要求，
而 20,000 条数据是这个项目最主要的价值。Apache-2.0 补上了专利授权条款，
CC BY 4.0 明确了数据的署名义务。

**旧版本取得的授权还有效吗？**

有效。MIT 一经授予不可撤销，已发布的 3.0.x 版本仍按 MIT 使用。

## 关于使用

**复制了 CSS，元素不动。**

少了 HTML 结构或关键帧定义。三件套要一起取 —— 详情页的复制按钮复制的是完整的一份。

**动效一闪就没了。**

入场动画默认只播一次，这是刻意的。要循环请显式改 `animation-iteration-count`，
但同屏循环别超过 2 个，否则会很吵。

**手表上卡顿。**

手表禁用 canvas、blur、无限循环。用 `--device watch` 取码时，
`packages/core` 会在 `warn` 里提示命中了哪些禁用项。

**能直接用在 React / Vue 里吗？**

能。输出的是普通 HTML + CSS（少数带一小段 JS），
把 `class` 改成 `className`、把内联 JS 挪到 `useEffect` / `onMounted` 即可。

**有 TypeScript 类型吗？**

暂时没有。数据结构定义在 `packages/schema/*.schema.json`，可以自己生成类型。

## 关于安装

**为什么 Windows 包这么大（112 MB / 解压 293 MB）？**

因为内置了完整的 Electron 运行时（Chromium + Node）。
这样做的好处是完全离线、不依赖系统内核版本；代价就是体积。

**有更小的版本吗？**

[`legacy/pyinstaller-windows/`](../legacy/pyinstaller-windows/) 里保留了早期
基于系统 WebView2 的实现，单文件约 113 MB，但冷启动更慢，且未随 3.1 之后验证。

**APK 为什么要「未知来源」权限？**

因为没上应用商店。APK 直装都需要这一步，与权限申请无关 —— 应用本身不申请任何权限。

**应用联网吗？**

不联网。网页版是纯静态文件；桌面与安卓把资源打进包里。
没有埋点、没有更新检查的强制请求、没有账号。

**为什么包名是 `com.transientlab.motion` 而不是 zingdex？**

历史原因。项目叫过 TRANSIENT → FrameFolio → Zingdex，包名一直没改。
改了老用户就无法覆盖升级，数据会丢。名字可以换，包名不能。

一个人。所以更新频率是每周最多一次，Issue 响应通常在周末。

不会。「收费闭环、小程序、账号体系暂不启动」写在 README 里，

**我能 fork 自己维护吗？**

能。Apache-2.0 与 CC BY 4.0 都允许。只要遵守商标政策，不叫 Zingdex 就行。

**项目停了怎么办？**

仓库保持公开，许可证继续有效，任何人都可以 fork 继续。
开源许可的意义就在于此：项目可以停，代码不会消失。
