## 这份文档记录什么

只记**能自动算出、且能反映项目健康度**的数字。不记 Star 数、不记下载量 ——
那些是平台给的、会波动的、也说明不了项目本身的问题。

| 看 | 为什么 |
|---|---|
| 条目数 / 特效数 | 内容规模是否名实相符（README 里写的数字必须对得上） |
| 仓库体积 | 影响 clone 成本；超过 500 MB 就该拆分数据 |
| `apps/web` 占比 | 数据是主体，若代码占比反超，说明结构出了问题 |
| 各部分文件数 | 某个目录突然膨胀，通常是产物误入版本库 |
