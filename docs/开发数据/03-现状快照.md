## 六、构建入口

```bash
# 动效数据（改了场景定义才需要）
python tools/gen_v2.py

# 站点数据
node tools/build_library_data.js && node tools/gen_site_data.js

# Android
cd android && bash build_apk.sh

# 桌面端（含自检）
bash build_desktop.sh

# 安装包 + 便携版
cd tools && python pack_installer.py

# 密钥 App
cd keysapp && bash build_apk.sh
```

## 七、已知限制（照实写）

1. **纯前端，无服务端**。激活状态、等级、额度都在本机，改本地状态即可绕过。
2. **密钥 App 内是明文激活码**（0.0.1.7 起刻意回退加密），APK 不可外发。
3. **电脑端依赖系统 Edge/Chromium 内核**，随包自带，无外部依赖。
4. **便携版没有卸载入口**，只有清除脚本。
5. 单文件安装包 112–117 MB，每版都背着这个体积。
