# Zingdex · 开发数据

这个目录是**从本机真实文件还原出来的开发档案**，不是回忆录。
所有时间、体积、版本号都能在源文件里对上。

- 整理时间：2026-11-02
- 数据基准：`（本机路径））
- 当前版本：**v1.12.27**（2026-11-01）

## 目录

| 文件 | 内容 |
|---|---|
| `01-开发时间线.md` | 从第一版到 v1.12.27 的完整过程，分五个阶段 |
| `02-版本与产物数据.csv` | 46 个构建产物的机器可读表（版本 / 时间 / 形态 / 体积 / 要点） |
| `03-现状快照.md` | 截至今天的真实状态：四个端、体积、单点真相、已知限制 |
| `04-后续路线.md` | 往后怎么走：已写明的计划、合理的推断、以及不确定性 |
| `05-数据来源与口径.md` | 每条数据出自哪个文件，哪些是事实、哪些是推断 |

## 怎么用

- 想快速了解做了什么 → 看 `01-开发时间线.md`
- 想查某个版本改了什么 → 查 `02-版本与产物数据.csv`
- 想接手继续开发 → 先看 `03-现状快照.md` 的「单点真相」与「已知限制」
- 想规划下一步 → 看 `04-后续路线.md`，注意区分「已写明」和「推断」
