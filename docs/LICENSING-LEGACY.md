# 授权版本说明 · 所有已发布版本仍带授权界面

> 结论先说：从 **v0.0.1 到 v2.1.3**，本仓库里的每一个版本，安装包内都还保留着早期的
> 授权界面（等级 / 激活码 / 管理员令牌）。免费化之后这套体系已停用，但代码尚未移除。

---

## 一、怎么判断一个版本带不带授权

打开应用 → 设置 → 看有没有下面任一入口：

| 入口 | 说明 |
|---|---|
| 等级阶梯 / 10 级 | 用户等级与每日额度 |
| 激活码输入框 | 输入 00001–10000 或 S 码 |
| 管理员令牌（`.token`） | 仅 Windows 安装版可见 |
| 密钥 / 授权区块 | 查看当前等级与到期 |

**有其中任意一个，就是「带授权」的版本。**

实测结果（解包 APK 检索关键词）：

| 版本 | 激活码 | 管理员令牌 | S 级 | 等级 |
|---|---|---|---|---|
| 1.12.43 | 有 | 有 | 有 | 有 |
| 2.1.3（最新） | 有 | 有 | 有 | 有 |

也就是说：**最新版也没有去掉授权层。**

## 二、这套授权体系原本是怎么设计的

| 组成 | 说明 |
|---|---|
| 普通等级 1–10 | 每级对应每日额度，第 1 级 100 次/天，每级 +300 |
| S 级 | 1000 枚（S0001–S1000），不限次数 |
| 管理员令牌 | `.token` 文件，仅 Windows 安装版可用，会话级有效 |
| 密钥 App | 安卓端查看 / 领取激活码，指纹解锁 |
| 离线密钥库 | Windows 端，不联网，主密码解锁 |

**四端能力差异**（早期设计）：

| 端 | 可用授权 |
|---|---|
| Windows 安装版 | 1–10 级 + S 级 + 管理员令牌 |
| Windows 便携版 | 1–10 级 + S 级 |
| 安卓 | 1–10 级 + S 级 |
| 网页 | 只读展示 |

## 三、现在的状态

| 事项 | 状态 |
|---|---|
| 软件本体 | **免费使用**，功能不受限 |
| 授权体系 | 已停用，不再发放新码 |
| 密钥 App | 历史存档（Releases → `keys-v0.0.1.8.zwb`） |
| 离线密钥库 | 历史存档 |
| 激活码 | 仅存在于旧安装包与密钥 App 内，**不再作为授权依据** |

> 换句话说：授权界面还在，但它现在只是一段没有意义的旧代码。

---

## 四、安全提醒（重要）

1. **安装包里是明文激活码**。解包 APK 就能拿到完整名单。
   这在免费模式下无所谓；但**不要把这些码当成"正版授权"去卖或去证明授权**。
2. **密钥 App 不要外发**给他人当工具用——它只是历史存档。
3. 如果你要做正式发布（上架商店 / 商用），**请先出一版去掉授权层的构建**，
   否则审核与用户都会困惑「到底要不要激活」。

## 五、去授权要改哪些地方

| 位置 | 处理 |
|---|---|
| 设置页授权区块 | 整块删除 |
| 等级阶梯 / 额度逻辑 | 删除 |
| 激活码校验 | 删除 |
| 管理员令牌导入 / 拖拽 | 删除 |
| 密钥 App | 停止分发 |
| 关于页的等级说明 | 改为「免费版」 |

改完建议直接进 **3.0.0**，与带授权的 1.x / 2.x 明确区分。
