# TRANSIENT 瞬态 · 动效取用技能

这份技能的目标：**任何一次「找个动效用」都必须有确定结果**，不允许出现「查不到」。

## 强制流程（不许跳步）

```
1. 读  references/02-retrieval.md     ← 检索顺序与降级策略
2. 跑  tools/find-motion.js           ← 拿到场景与条目编号 fx-...
3. 跑  tools/extract-motion.js        ← 按特效编号取三件套代码
4. 读  references/04-device-rules.md  ← 按目标设备乘系数、排除禁用项
5. 对照 第七节「交付契约」自查
```

**先查再答。** 凭记忆编造编号（如 `enter-99`）是本技能最严重的错误。

---

## 一、这个库是什么

- 组件 **20,000** 条：场景化的界面动效，每条都是真实结构 + 动效
- 特效基底 **500** 个，18 个族
- 场景 **201** 个，覆盖 **11** 类设备
- 完全离线，不依赖任何外部资源

三层结构：**场景 → 条目 → 特效**（详见 `references/01-data-model.md`）。

| 层 | 编号示例 | 用途 |
|---|---|---|
| 场景 | `s001` / `n001` | 定位「在什么界面里」 |
| 条目 | `fx-s001-07` | 定位「这个场景的第几条」 |
| 特效 | `enter-01` | **取代码用这个** |

> 条目编号 ≠ 特效编号。混用会查不到，这是最常见的失败原因。

## 二、工具

```bash
# 找场景与条目（输出 fx 编号）
node skill/tools/find-motion.js <库目录> "商品列表" --device phone

# 按特效编号取 HTML/CSS/JS
node skill/tools/extract-motion.js <库目录> enter-01

# 列出全部特效编号（按族）
node skill/tools/extract-motion.js <库目录> --list
node skill/tools/extract-motion.js <库目录> --list light
```

`<库目录>` 指应用源码的站点目录（含 `assets/engine*.js`）。
路径不确定时先 `ls`，不要猜。

## 四、取到代码后必须做的适配

```
实际时长 = 基准时长 × durScale
实际位移 = 基准位移 × distScale
```

手机 ×0.82 / ×0.72 · 手表 ×0.62 / ×0.55 · 车机 ×0.75 / ×0.70 · 桌面大屏 ×1.08 / ×1.18

禁用项命中就**换方案**，不能「差不多」：
- 手表：不许画布 / WebGL / 模糊 / 3D / 位移>16px / 无限循环
- 车机：不许画布 / 无限循环 / 高饱和闪烁 / 视差 / 3D
- 终端：点击热区 ≥56px

## 五、硬约束

1. 三件套同取：只拿 CSS 会「不动」，只拿 HTML 会「没效果」
2. 关键帧名不要改，改了要同步改 HTML 引用
3. 入场只播一次，不要 `infinite`
4. 同屏循环 ≤2
5. 有 `prefers-reduced-motion` 兜底（直接给终态，不是放慢）
6. 粒子 / 物理类：元素移除时必须停掉帧循环

## 六、查不到怎么办（降级链）

```
① 换更短的词
② 去掉 --device / --cat / --max 限制
③ 用 --list 看实际存在的编号
④ 检查 <库目录>/assets/engine.js 是否存在
⑤ 确认版本：不同版本的场景数与编号会变
```

**永远以 `--list` 的实际输出为准**，不要根据规律推测编号。

## 七、交付契约

回答用户时，必须包含：

1. 场景：中文名 + id
2. 条目：中文名 + 时长 + 类别
3. 代码：三件套齐全，或明确说「该条无需 JS」
4. 适配：目标设备的系数与是否命中禁用项
5. 来源：引用的文件与编号

缺任何一项视为未完成。

## 八、边界

- 本库是**素材与规格**，不是框架；接入由使用方负责
- 特效代码可改时长/缓动/颜色，不建议改结构
- 2.0.0–2.1.3 的变更未记录，**不要根据版本号推断变化**
