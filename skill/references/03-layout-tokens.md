# 03 · 版面参数（设计令牌）

所有数值来自 `spec/tokens.json`，是库的统一口径。**改数值可以，改结构不行。**

---

## 一、时长

| 令牌 | 毫秒 | 用在哪 |
|---|---|---|
| instant | 120 | 按下反馈、选中态 |
| fast | 160 | 小元素出现、提示 |
| base | 240 | 常规切换 |
| standard | 320 | 卡片、页面元素 |
| emphasis | 480 | 强调、旗舰动效 |
| loop | 1600 | 循环周期 |

**规则**：入场 ≤ 480；退场 ≤ 320；循环周期 ≥ 1200（再快会晕）。

## 二、缓动

| 名称 | 曲线 | 感觉 |
|---|---|---|
| `out` | `cubic-bezier(0.16, 1, 0.3, 1)` | 快进慢停，最常用 |
| `outc` | `cubic-bezier(0.33, 1, 0.68, 1)` | 更柔的出场 |
| `inout` | `cubic-bezier(0.76, 0, 0.24, 1)` | 对称，适合转场 |
| `spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 回弹，慎用 |
| `linear` | `linear` | 只用于匀速循环 |

**默认用 `out`。** 回弹 `spring` 每屏最多一个。

## 三、错峰（stagger）

- 列表逐项入场：**70 ms / 项**
- 超过 8 项时改用「分批」：每 8 项一批，批间 120 ms
- 错峰总时长不超过 600 ms，否则用户会等

## 四、配色

| 令牌 | 值 | 用途 |
|---|---|---|
| accent | `#C6F24C` | 主强调色（荧光黄绿） |
| accentText | `#4F6B00` | 强调色上的文字 |
| line | `#E7E4DA` | 分隔线 |
| surface | `#FFFFFF` | 卡片底 |
| ink | `#14160F` | 主文字 |

深色主题下：surface 换深底，ink 换浅字，accent 保持不变。

## 五、画布与圆角

| 项 | 值 |
|---|---|
| 特效画布 | 340 × 240 px |
| 圆角 | 16 px |
| 内边距 | 0（画布铺满） |

预览卡片按 340:240 的比例铺满，不要留白边——这是库内统一做法。

## 六、在代码里怎么用

库内 CSS 用变量控制节奏，接入时只需覆盖变量：

```css
.my-container{
  --fx-dur: 420ms;
  --fx-ease: cubic-bezier(0.16, 1, 0.3, 1);
}
```

不要直接改 `@keyframes` 里的百分比——那会破坏与 HTML 结构的对应关系。

## 七、与设备系数的关系

上面是**手机基准值**。换设备时：

```
实际时长 = 基准时长 × durScale
实际位移 = 基准位移 × distScale
```

系数见 `04-device-rules.md`。
