# 04 · 设备适配（硬约束）

同一套动效在不同设备上**必须**改变节奏与幅度。数值来自 `spec/device-tokens.json`。

```
实际时长 = 基准时长 × durScale
实际位移 = 基准位移 × distScale
禁用项命中 → 必须换方案，不能「差不多」
```

---

## 一、全表

| 设备 | 时长系数 | 位移系数 | 同屏并发 | 禁用项 |
|---|---|---|---|---|
| 手机（小屏） | ×0.82 | ×0.72 | 3 | 动画模糊、大背景模糊、重画布 |
| 手机（大屏） | ×0.88 | ×0.80 | 3 | 动画模糊、大背景模糊 |
| 折叠屏 | ×1.00 | ×1.05 | 4 | — |
| 平板 / iPad | ×1.00 | ×1.00 | 5 | — |
| 笔记本 | ×1.00 | ×1.00 | 6 | — |
| 桌面大屏 | ×1.08 | ×1.18 | 8 | — |
| **手表** | ×0.62 | ×0.55 | 2 | 画布、WebGL、模糊、背景模糊、CSS 3D、位移>16px、旋转>15°、无限循环 |
| **电视** | ×1.15 | ×1.35 | 4 | 仅悬停才触发的效果、时长<180ms |
| **车机** | ×0.75 | ×0.70 | 2 | 画布、无限循环、高饱和闪烁、视差、CSS 3D |
| **自助终端** | ×1.00 | ×1.10 | 3 | 点击热区<56px |
| **降级**（用户关闭动效） | ×0.00 | ×0.00 | 1 | 位移动画、画布、循环、视差、CSS 3D |

## 二、三条硬规矩

1. **手表不要用粒子 / 画布**。改成纯 CSS 关键帧，位移 ≤16px。
2. **车机不要循环、不要高饱和闪烁**，防眩光；单次播放，≤400ms。
3. **终端热区 ≥56px**，手指点不准。

## 三、为什么不能照搬

同一段「上滑入场」，在四种设备上的实测值：

| 设备 | 时长 | 位移 |
|---|---|---|
| 竖屏手机 | 420 ms | 14.9 px |
| 桌面大屏 | 546 ms | 30.4 px |
| 车机 | 399 ms | 14 px |
| 手表 | 320 ms | 10 px |

照搬手机参数到大屏 → 显得又慢又小；到车机 → 晃眼；到手表 → 直接卡。

## 四、怎么落地

```js
const D = { phone: 0.82, "desktop-xl": 1.08, watch: 0.62, car: 0.75 };
const ms = baseMs * (D[device] || 1);
```

或直接用 CSS 变量：

```css
:root[data-device="watch"]{ --fx-dur: 320ms; }
:root[data-device="car"]  { --fx-dur: 400ms; }
```

## 五、降级（prefers-reduced-motion）

```css
@media (prefers-reduced-motion: reduce){
  *{ animation-duration: 1ms !important; animation-iteration-count: 1 !important; }
}
```

用户明确关闭动效时，**直接给终态**，不要「放慢播放」。
