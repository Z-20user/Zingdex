# 07 · 接入方式与范式

三种接入方式 + 一套可复用的框架范式（网页 / APK / exe 通用）。

---

## 一、三种接入方式

| 方式 | 适合 | 代码量 | 控制力 |
|---|---|---|---|
| A. 直接复制 | 只要一两条 | 最少 | 高（可随意改） |
| B. 运行时 | 一次要很多条 / 动态切换 | 中 | 中 |
| C. 组件封装 | 工程化项目 | 多 | 高 |

### A. 直接复制

```html
<div class="fx-enter-01">
  <div class="fx-enter-01__card">你的内容</div>
</div>
```

```css
.fx-enter-01{ /* 来自 engine_css.js */ }
@keyframes kf-enter-01{ /* 同上 */ }
```

**关键帧名不要改**，改了要同步改 HTML 里的引用。

### B. 运行时

```html
<div data-motion="enter-01">你的内容</div>
<script src="runtime/index.js"></script>
```

适合列表里批量挂载；运行时自带「离屏暂停、移除即停」。

### C. 组件封装

`components/motion-data.js` 是 `{ id: { html, css } }` 的映射，
可以遍历生成 React / Vue 组件。

## 二、框架范式（APK / exe / 网页通用）

分层只有四层，**不要为了炫技加层**：

```
① 壳层  页面容器、路由、主题
② 数据层 场景 + 条目（只读，不参与渲染逻辑）
③ 渲染层 把条目解析成「HTML + CSS + JS」
④ 适配层 设备系数、降级、性能守则
```

### 2.1 壳层

- 手机：单页 + 底部返回栈
- 桌面：单窗口 + 侧栏
- 网页：路由 + 滚动

**要求**：壳层不关心动效细节，只负责容器尺寸与主题变量。

### 2.2 数据层

只读。任何「改数据」的需求都应落到生成脚本，不要运行时改。

### 2.3 渲染层

一条动效 = 三件套：

```
HTML 结构  +  CSS（含 @keyframes）  +  可选 JS（粒子/物理）
```

渲染时按 `id` 拼装，**不要做字符串替换式注入**（会破坏类名对应）。

### 2.4 适配层

```js
const DEVICE = {
  phone:      { dur: 0.82, dist: 0.72, max: 3 },
  "phone-lg": { dur: 0.88, dist: 0.80, max: 3 },
  watch:      { dur: 0.62, dist: 0.55, max: 2 },
  car:        { dur: 0.75, dist: 0.70, max: 2 },
  "desktop-xl":{ dur: 1.08, dist: 1.18, max: 8 },
};
```

```html
<html data-device="phone">
```

```css
:root[data-device="watch"]{ --fx-dur: 320ms; --fx-dist: 10px; }
```

探设备用视口宽度 + 输入方式（`pointer: coarse`），**不要用 UA 字符串**。

## 三、性能守则（血泪）

| 问题 | 原因 | 解法 |
|---|---|---|
| 列表滚动卡 | 每张卡都建帧循环 | 离屏暂停（`IntersectionObserver` 或视口扫描） |
| 翻页后越来越慢 | 元素移除但循环没停 | 移除时 `cancelAnimationFrame` |
| 首屏空白 | 画布在隐藏容器里建成 0×0 | 挂载后补一次 `resize` |
| 中低端机掉帧 | 同屏循环 >2 / 用了粒子 | 降级到 CSS 关键帧 |
| 首帧闪一下 | 初始态未对齐 | 首帧同步绘制，或用 `animation-fill-mode: backwards` |

---

## 四、交付前校验

- [ ] HTML / CSS / JS 三件齐全
- [ ] 类名一致（`fx-<id>`）
- [ ] 时长按设备乘过系数
- [ ] 没有命中该设备的禁用项
- [ ] 循环类动效同屏 ≤2
- [ ] 有 `prefers-reduced-motion` 兜底
- [ ] 移除元素时停止帧循环
- [ ] 深色/浅色主题下都看过

---

## 五、不推荐的做法

| 做法 | 为什么不行 |
|---|---|
| 把所有特效 CSS 一次性塞进页面 | 2.8 MB，首屏必卡 |
| 用 `infinite` 当入场 | 用户看两遍就烦 |
| 在手表上用粒子 | 直接卡死 |
| 改 `@keyframes` 却不同步类名 | 静默失效，最难查 |
| 用 UA 判断设备 | 折叠屏、平板全判错 |
