# 01 · 数据模型

三层结构：**场景 → 条目 → 特效**。任何一次取用都要穿过这三层。

---

## 一、三层是什么

| 层 | 数量 | 作用 | 在哪里 |
|---|---|---|---|
| 场景 scene | 201 | 描述「在什么界面里用」 | `assets/data.js` + `assets/engine.js` |
| 条目 cat | 20,000 | 场景里的一条具体动效 | 场景对象的 `cats[]` |
| 特效 effect | 500 | 真正可复用的代码单元 | `assets/engine_html.js` / `engine_css.js` / `engine_js.js` |

```
场景 n001（商品列表）
 ├─ 条目 fx-n001-01  「进度跳变」 420ms   ──┐
 ├─ 条目 fx-n001-02  「磁场线」   450ms     ├─ 各自解析到一个特效基础编号
 └─ 条目 fx-n001-47  …                     ──┘   （如 enter-01 / light-07）
```

---

## 二、场景对象字段

```js
{
  id: "n001",              // 场景 id（唯一）
  ctx: "ecommerce-list",   // 英文上下文，用于跨语言检索
  zh: "商品列表",           // 中文名
  en: "Ecommerce List",    // 英文名
  desc: "快速扫视，找东西；快、利落，不能拖",  // 一句话说明
  domain: "电商",           // 领域
  g: "电商",                // 分组（与 domain 多为同值）
  f: "phone",              // 形态：phone / wide / vehicle / wear / terminal
  kind: "phone",
  devices: ["phone"],      // 适用设备
  cats: [ /* 条目数组 */ ]
}
```

## 三、条目字段

```js
{
  zh: "进度跳变",     // 条目中文名
  en: "Progress Jump",// 条目英文名（**按它查更稳**）
  ms: 420,           // 时长（毫秒）
  ease: "out",       // 缓动名，对应 tokens.easing
  fam: "m01",        // 母版编号
  t: 0,              // 变体偏移
  fx: "fx-n001-01",  // 条目编号（场景内唯一）
  mc: "入场",         // 动效类别：入场/列表/循环/文字/状态/进度/数值…
  fq: 5              // 使用频率，越大越常用
}
```

## 四、代码到底存在哪里（关键）

```
条目 cats[].fx = "fx-n001-01"
        ↓
LIB_PAY["fx-n001-01"] = { h: HTML, c: CSS, nt: 备注 }
```

- `LIB_PAY` 定义在 `site/assets/lib/d001.js … d201.js`（每个场景一个文件）
- **20,000 条条目全部命中**，实测命中率 100%
- 取码工具直接吃 `fx-…` 编号，没有中间映射

另有一套 **500 个基础特效**（`ENGINE_HTML/CSS/JS`，编号 `enter-01` 这类），
是独立素材池，不绑定场景；工具同样支持。

| 编号 | 例子 | 位置 | 建议 |
|---|---|---|---|
| 条目编号 | `fx-n001-01` | `LIB_PAY` | **首选**，场景化 |
| 基础特效 | `enter-01` | `ENGINE_*` | 通用素材，需自配界面 |

## 五、特效对象里有什么

| 文件 | 键 | 值 |
|---|---|---|
| `engine_html.js` | 特效编号 | HTML 字符串（含 `fx-<id>` 类名） |
| `engine_css.js` | 特效编号 | CSS 字符串（含 `@keyframes kf-<id>`） |
| `engine_js.js` | 特效编号 | 函数 `(R) => {}`，仅 123 条有 |

**三件套必须同取**：只拿 CSS 会「不动」，只拿 HTML 会「没效果」。

## 七、数据版本

- 数据结构版本：`spec/catalog.json` 里的 `version`（当前 3.0.0）
- 应用版本：`app_version.py` 的 `VERSION_NAME`
- 两者不同步，检索时以**应用版本**为准
