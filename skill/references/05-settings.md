# 05 · 应用内设置

设置项定义在 `site/settings.html`，键名以 `data-set` 属性存储，共 14 项。
默认值随版本可能调整，**以应用内显示为准**。

---

## 一、外观类

| 键 | 名称 | 取值 | 影响 |
|---|---|---|---|
| `theme` | 主题 | 浅色 / 深色 / 跟随系统 | 全站配色 |
| `skin` | 特色皮肤 | 默认 / 极光 / 星野 / 玻璃 / 纸感 / 晨雾 | 整页氛围（背景光带、星点、磨砂等） |
| `density` | 密度 | 紧凑 / 标准 / 宽松 | 列表项间距、卡片排布 |
| `fs` | 字号 | 小 / 标准 / 大 / 特大 | 正文整体缩放 |
| `lh` | 行距 | 紧凑 / 标准 / 宽松 | 正文行高 |
| `cardSize` | 卡片尺寸 | 小 / 中 / 大 | 组件库网格列宽 |

## 二、行为类

| 键 | 名称 | 取值 | 影响 |
|---|---|---|---|
| `motion` | 动效总开关 | 开 / 关 | 关闭后所有预览静止，只显示终态 |
| `cardAnim` | 列表卡片动效 | 播放 / 静止 | 列表里是否让卡片动起来 |
| `codeFont` | 代码字体 | 等宽 / 系统 | 详情页代码块 |
| `fullscreen` | 启动全屏 | 开 / 关 | 桌面端打开即全屏（Esc / 右键 / F11 退出） |

## 三、组件库默认视图

| 键 | 名称 | 说明 |
|---|---|---|
| `libGroup` | 进入组件库先看哪一类 | 记住上次的分类 |
| `libDevice` | 设备筛选 | 手机 / 大屏 / 车机 / 手表 / 终端 |
| `libSort` | 排序方式 | 按频率 / 按时间 / 按名称 |
| `libShown` | 显示条数 | 每页或首屏条数 |

## 四、给 AI 的用法

1. **不要假设设置默认值**，需要时读 `settings.html` 或让用户在应用里确认
2. 生成示例代码时，遵循用户当前主题（深色下不要给浅色底）
3. 用户关闭动效（`motion=关`）时，产出**终态样式**而不是更慢的动画
4. 皮肤只影响背景与氛围，不影响组件代码

## 五、设置与代码的关系

| 设置 | 影响代码吗 |
|---|---|
| theme / skin / density / fs / lh / cardSize | 影响**容器样式**，不影响特效代码 |
| motion / cardAnim | 决定是否加载动画 |
| codeFont | 只影响代码展示 |
| fullscreen | 只影响桌面窗口 |

> 换句话说：**特效代码与皮肤解耦**。复制代码时不用担心用户选了什么皮肤。
